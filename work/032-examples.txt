# CAS 032's examples (work/032-redundant-row.md; Michael's (b), card cas-032-rows, abacus #10706; h032's reading
# #10639): a letter's row that another row says, left out. A letter's row L≠0 goes where a kept row has a value at
# L = 0 and is false there, its other letters in a sum, a product or a whole power; a '?' row (CAS 030's) says it only
# on a line that keeps that row. Each row is run by scripts/doc-examples.py, and again with the series route compiled
# out (CAS 021) and through the value check's build (CAS 022 rule 5).

# - The redundant row (1.2.0's Not yet) and its kin: a ratio that is 1 at its letter's 0 (COS, EXP, COSH, Z^2+1), a
#   monomial's ABS row, and CAS 026's factor row, which is false at Y = 0 for every Z

| `casim sum '(Z^2+1)^K' K 0 N RAD` | `-1÷Z^2+(Z^2+1)^(N+1)÷Z^2; Z^2+1≠1` |
