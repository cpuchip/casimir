# CAS work unit 040: a coefficient of X that is 0 where canon can't see it

**From:** casim · **To:** abacus · **Status:** BLUEPRINT (abacus #14959), for abacus's rulings and the hidden set,
which abacus freezes from this file before any src. The number is abacus's. The rows below were measured on a throwaway
prototype, p1, over b54187a (1.6.0's notes commit; the code is the v1.6.0 tag's). casim writes the unit; abacus writes
the hidden set and the acceptance.
- **Why now:** 1.6.0's first "Not yet" item, and Michael's ask (through abacus) that the last of the subscription go to
  well defined work.
- **The question:** when X's coefficient is 0 for every value of its letters but canon prints it as something else, can
  solve stop printing SOLVED, without refusing equations whose coefficient isn't 0?

## Where it is today

CAS 038 collects L - R as a×X + b and prints X = -b÷a with the row a≠0. When a is 0 for every value of its letters, that
row never holds. Nothing printed is false, but there is no solution and SOLVED says there is one:

| Command | 1.6.0 prints |
|---|---|
| `casim solve '(SIN(A)^2+COS(A)^2-1)×X=1' X RAD` | `SOLVED: X=1÷(SIN(A)^2+COS(A)^2-1); SIN(A)^2+COS(A)^2-1≠0` |
| `casim solve '(SIN(A)^2+COS(A)^2-1)×X=0' X RAD` | `SOLVED: X=0; SIN(A)^2+COS(A)^2-1≠0` |
| `casim solve '(EXP(A+B)-EXP(A)×EXP(B))×X=C' X RAD` | `SOLVED: X=C÷(EXP(A+B)-EXP(A)×EXP(B)); EXP(A+B)-EXP(A)×EXP(B)≠0` |
| `casim solve 'A×X-A×X=1' X RAD` | `NOT_NUMERIC` (a 0 canon sees: X drops out, as 1.6.0's notes list) |

## How "identically 0" is decided: a point test

**Where:** in ls_solve, once a and b are collected and a isn't 0 by form, before the answer is formed. Every letter
solve that would print SOLVED passes it. It is one new function, out of line (ls_zero), and one call.

**The points:** four fixed points, each giving every letter its own value. For letter l (A is 0, Z is 25), n = l + 1,
at point j the value is s × (R n + K) ÷ (n + D), with (R, K, D) = (1, 1, 9), (1, 3, 5), (2, 7, 3), (6, 13, 2) for j = 0
to 3. The sign s is + for an even letter at points 0 and 3 and - at points 1 and 2, the other way for an odd letter.
So A takes 1/5, -2/3, -9/4 and 19/3; B takes -3/11, 5/7, 11/5 and -25/4; Z takes -27/35, 29/31, 59/29 and -169/28.
The table was checked (exact rationals, a script) for:
- no integer value, and no magnitude within 1/20 of 0 or 1;
- the 26 magnitudes distinct at each point;
- no relation that holds at all four points, among integer combinations c1·u + c2·v (+ c3·w) + k = 0 of up to three
  letters with every coefficient between -4 and 4, or among products u×v = k×w with k one of 1, -1, 2, -2, 1/2. So a
  coefficient such as `A-2×B+C` or `3×A+2×B` can't read 0 at every point.

**At each point,** every letter of a is put to its value (ib_at, then canon), and the constant is read by CAS 022's
rule 8 evaluator, the one lm_sgn uses for every sign Casimir prints: a value with a bound on its error, about 1E-32 of
the magnitudes it was formed from. Each point gives one of four readings:
- **not 0:** an exact nonzero number, or |value| above 8 times its bound, the line lm_sgn uses;
- **reads 0:** an exact 0, or |value| within 8 times its bound;
- **no value:** canon gives UNDEFINED (a pole at the point), or the constant has no real value there (LN or SQRT of a
  negative). The point is outside the text's domain and is skipped;
- **not read:** the evaluator can't form the value: IP, FP, a function in an exponent (`10^LOG(A)`), or a constant
  nested past S_EVAL_DEPTH.

**The outcome:**

| What the four points read | solve prints |
|---|---|
| not 0 at any point (it stops at the first) | 1.6.0's answer, unchanged |
| reads 0 at one point or more, and not 0 at none | `NOT_NUMERIC`, pw's refusal, which 1.5.0 printed for every letter equation and 1.6.0 prints for `A×X-A×X=1` |
| no point read (each one no value or not read) | 1.6.0's answer, unchanged |

## How sure, and what happens when it can't be sure

- **"Not 0" is sure,** on the same bound that every sign Casimir prints rests on (CAS 022 rule 8). Where one point says
  not 0, a is not 0 there, the row a≠0 holds there, and 1.6.0's answer is right.
- **"Reads 0" is never a proof, and the unit doesn't treat it as one.** CAS 022's rule 1 says Casimir never takes a
  value as 0 from its digits, so a coefficient that reads 0 is refused, not answered. The line is the refusal Casimir
  already prints for a 0 it can see. There is no new word, no NO SOLUTION and no EVERY X for letter text in this unit
  (see the alternatives below).
- **A refusal where 1.6.0's answer was right** needs a coefficient that isn't 0 but reads 0 at all four points. Three
  shapes do it, and each is refused, never answered wrongly:
  1. 0 on a region that holds every point: `(ABS(A+5)-(A+5))×X=1` is 0 for A≥-5, and every one of A's values is in
     that region. 1.6.0's `SOLVED: X=-1÷(A-ABS(A+5)+5); -A+ABS(A+5)-5≠0` was right (it holds for A<-5).
  2. A factor built to vanish at the table's points, such as `(A-1÷5)×(A+2÷3)×(A+9÷4)×(A-19÷3)×SIN(A)`.
  3. A part smaller than about 1E-31 of the coefficient's terms at every point: `(SIN(A)^2+COS(A)^2-1+10^-40)×X=1`.
- **SOLVED still prints for a 0 coefficient where no point is read:** `(IP(A)+FP(A)-A)×X=1`, `(10^LOG(A)-A)×X=1`, and
  `(2×LN(A-7)-LN((A-7)^2))×X=1`, whose domain A>7 holds none of A's four values. These print 1.6.0's line unchanged.

## For ruling

1. **The refusal** (above) against a word. My lean is the refusal, because it keeps CAS 022 rule 1 and is never false.
2. **No point read keeps 1.6.0's answer.** The other choice refuses there too, which would also refuse `IP(A)×X=1`
   (`SOLVED: X=1÷IP(A); IP(A)≠0`, whose row holds). My lean is to keep the answer.
3. **Not chosen, for the record:**
   - *Points as proof, printing NO SOLUTION (b not 0) or EVERY X (b reads 0 too).* That breaks rule 1, and shape 3 would
     print a false NO SOLUTION. Shape 2 would need points nobody can know in advance (seeded from a hash of the text).
     EVERY X would also need the typed conditions as rows (`LN(A)×X=X×LN(A)` holds only for A>0).
   - *A proof by rewriting SIN, COS, TAN and the hyperbolics as EXP of i×u.* canon doesn't reduce i^2 when letters are
     present, and doesn't join EXP(u)×EXP(v) (`expand` keeps `EXP(A)×EXP(B)-EXP(A+B)` as it is), so this would be a
     new engine. It belongs to the Not yet's trigonometric identities, and when canon sees such a 0, the refusal here
     is what prints for it.
   - *Words for a 0 canon sees* (`A×X-A×X=1` as NO SOLUTION, `A×X=X×A` as EVERY X, each with a steps page): a unit of
     its own if wanted. 040 leaves those rows as they are.
