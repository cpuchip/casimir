# CAS 041's examples (work/041-quadratics-with-letters.md; abacus #16650, #16688, h041 #16697): a quadratic or a
# pure power in var, letters as coefficients, by the formula with an exact square root where D has one, every root put
# back, rows on what is printed and read together at a witness point; and x^n = c with numbers, solved whole. Each
# row is run by scripts/doc-examples.py, and again with the series route compiled out (CAS 021) and through the value
# check's build (CAS 022 rule 5).

# - Part 1: the formula, and a perfect square

| Command | Prints (lines joined by " / ") |
|---|---|
| `casim solve 'A×X^2+B×X+C=0' X RAD` | `SOLVED: X=-(B+SQRT(B^2-4×A×C))÷2÷A; X=-(B-SQRT(B^2-4×A×C))÷2÷A; A≠0; B^2-4×A×C≥0` |
| `casim solve '(A+D)×X^2+B×X+C=0' X RAD` | `SOLVED: X=-(B+SQRT(B^2-4×A×C-4×C×D))÷2÷(A+D); X=-(B-SQRT(B^2-4×A×C-4×C×D))÷2÷(A+D); A+D≠0; B^2-4×A×C-4×C×D≥0` |
| `casim solve 'X^2-(A+B)×X+A×B=0' X RAD` | `SOLVED: X=A; X=B` |
| `casim solve 'X^2-2×A×X+A^2-B^2=0' X RAD` | `SOLVED: X=A+B; X=A-B` |
| `casim solve '(A-1)×X^2+A×X+1=0' X RAD` | `SOLVED: X=-1÷(A-1); X=-1; A≠1` |
| `casim solve 'X^2+2×A×X+A^2=0' X RAD` | `SOLVED: X=-A (MULT 2)` |
| `casim solve '4×X^2-12×A×X+9×A^2=0' X RAD` | `SOLVED: X=3×A÷2 (MULT 2)` |
| `casim solve 'X^2+A×X+1=0' X RAD` | `SOLVED: X=-A÷2-SQRT(A^2-4)÷2; X=-A÷2+SQRT(A^2-4)÷2; ABS(A)≥2` |
| `casim solve 'X^2+X=A' X RAD` | `SOLVED: X=-SQRT(4×A+1)÷2-1÷2; X=SQRT(4×A+1)÷2-1÷2; A≥-1÷4` |
| `casim solve '(X-A)^2=B' X RAD` | `SOLVED: X=A+SQRT(B); X=A-SQRT(B); B≥0` |
