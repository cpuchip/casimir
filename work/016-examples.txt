# CAS unit 016 visible examples (work/016-poles-and-follow-ups.md), written by casim. Each row is a command and what it
# prints; scripts/doc-examples.py runs every row (make check), and scripts/golden.py records each in the golden corpus.
# - Rule 1: a pole is UNDEFINED in every op and angle mode, as 1÷0 is: TAN where COS is 0 (π÷2 in RAD, 90 in DEG, 100 in
#   GRAD, and their odd multiples), LN and LOG of 0, ATANH of ±1. TAN(90) in RAD is no pole and is kept. The exits
#   with complex values stay symbolic, and solve's NOT_NUMERIC for a constant that isn't rational stays.
# - Rule 2: in X×ABS(X)'s derivative ABS(X)+X×SGN(X), SGN(0) beside the factor X (0 at 0) is 0, so order 1 answers 0
#   (f'(0) = 0); f'' = 2×SGN(X) jumps at 0, so order 2 is UNDEFINED, as ABS(X) is at order 1. ABS(X^3) is |X|^3: 0 to
#   order 2, UNDEFINED at 3 (X^3 changes sign at 0). ABS(X)^2 is X^2, whose order 2 the rule can't reach: UNDECIDED,
#   never a wrong answer; K×ABS(X) is UNDECIDED too (K may be 0).
# - Rule 3: 1÷X-1÷SIN(X) is (SIN(X)-X)÷(X×SIN(X)) → 0; 1÷LN(1+X)-1÷X → 1÷2; 1÷(EXP(X)-1)-1÷X → -1÷2;
#   1÷(X-1)-2÷(X^2-1) is 1÷(X+1) → 1÷2. In DEG, SIN(X) at 0 is π×X÷180, so 1÷X-1÷SIN(X) is (1-180÷π)÷X → -∞ from above.
#   1÷X^2-1÷SIN(X)^2 (-1÷3) needs about 15.7 KB: NO_ROOM at 8 KB until the series unit.
#   (1-COS(2×X))^2÷X^4 → 4 needs 6,280 B: it answers at the calculator's 8,800 only because each side's walk gets the
#   arena back (with the - side on top of the + side's work, NO_ROOM). Its 8 KB catcher, (1-COS(X))^2÷X^4, fits at 8,800.
# - A sibling of rule 1: derive's walk of 0^u says its derivative is 0 where it is defined, as derive does, not
#   LN(0)×0^u×d/dX(u), whose LN(0) is a pole.
# - Rulings during the build (abacus #7951): ABS(X)-SQRT(X^2) is 0, so its corner is cancelled by the other hole and
#   order 1 is UNDECIDED, not UNDEFINED. A 0÷0 that appears only in a derivative's formula is UNDECIDED (X×SQRT(X^2)'s
#   X^2×(X^2)^(-1÷2)), where a c÷0 is proof (X^(3÷2)'s 0.75×X^(-1÷2) at order 2: UNDEFINED). SINH, TANH, ASINH and
#   ATANH of 0 are 0, COSH(0) and ALOG(0) are 1, ACOSH(1) is 0 (ACOSH(0) has a complex value and is kept), so a pole
#   behind them is seen. A pole in any term decides solve and factor, whichever term comes first; X÷0 stays NOT_NUMERIC.
# - Rule 4: EXP(SIN(X)) to 9 needs the 1,024 B buffer, which an arena of 16,384 B or more has and 16,383 hasn't.
