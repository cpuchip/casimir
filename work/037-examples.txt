# CAS 037's examples (work/037-wrong-values.md; Michael's card cas037-wrong, abacus #11859, h037 #11884): a closed sum
# whose line had a value at a point where the typed sum has none. A power with K in its exponent is read as typed, as
# term by term reads it, and its base gets a hard row; a divisor in K alone that canon cancels, 0 at a whole K in
# range, makes the sum UNDEFINED. Each row is run by scripts/doc-examples.py, and again with the series route compiled
# out (CAS 021) and through the value check's build (CAS 022 rule 5).

# - Part 1: a factor that cancels the base's negative powers (CAS 036 printed each without the base's row, a value
#   there: 1 at Y = 1, Z = 0 for the first, 1 at Y = 0 for the second). To ∞ too. From a lo of 0, u^K has no negative
#   power and no row

| Command | Prints |
|---|---|
| `casim sum '(Y×SQRT(Z))^K×SQRT(Z)' K -1 N RAD` | `1÷(Y-Y^2×SQRT(Z))-(Y×SQRT(Z))^(N+2)÷(Y-Y^2×SQRT(Z)); Y≠0; Z≥0; Z≠0; Y×SQRT(Z)≠1` |
| `casim sum 'Y^K×Y' K -1 N RAD` | `-1÷(Y-1)+Y^(N+2)÷(Y-1); Y≠0; Y≠1` |
| `casim sum '(SIN(Z)×Y)^K×SIN(Z)' K -1 ∞ RAD` | `1÷(Y-Y^2×SIN(Z)); Y≠0; SIN(Z)≠0; ABS(Y×SIN(Z))<1` |
| `casim sum '(Y×SQRT(Z))^K×SQRT(Z)' K 0 N RAD` | `SQRT(Z)×(Y×SQRT(Z))^(N+1)÷(Y×SQRT(Z)-1)-SQRT(Z)÷(Y×SQRT(Z)-1); Z≥0; Y×SQRT(Z)≠1` |
