# CAS 042's examples (work/042-trig-integrals.md; abacus #17118, h042 #17132): a polynomial in SIN and COS of one
# angle θ = g×X+b0, put in one form p(C)+S×q(C) with C = COS(θ), S = SIN(θ) and S^2 = 1-C^2, integrated by ruling 1's
# parity split (-Q(C) where p = 0, R(S) where q = 0 and p is odd, both with one angle throughout; multiple angles
# otherwise), and checked in the same form. Each row is run by scripts/doc-examples.py, at the CLI's 8,800 B, and again
# with the series route compiled out (CAS 021) and through the value check's build (CAS 022 rule 5).

# - Part 1: one angle, the form S×q(C): a polynomial in COS

| Command | Prints (lines joined by " / ") |
|---|---|
| `casim integrate 'SIN(X)^3' X RAD` | `-COS(X)+COS(X)^3÷3` |
| `casim integrate 'SIN(X)^5' X RAD` | `-COS(X)+2×COS(X)^3÷3-COS(X)^5÷5` |
| `casim integrate 'SIN(X)^3×COS(X)^2' X RAD` | `-COS(X)^3÷3+COS(X)^5÷5` |
| `casim integrate 'SIN(2×X+1)^3' X RAD` | `-COS(2×X+1)÷2+COS(2×X+1)^3÷6` |
| `casim integrate '3×SIN(X)^3-SIN(X)' X RAD` | `-2×COS(X)+COS(X)^3` |

# - Part 2: one angle, q = 0 and p odd: a polynomial in SIN
