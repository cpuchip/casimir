# cause. The table is tests/frames/gcc-15.2.0-x86_64-linux-gnu.su, compiled as make check compiles src/casim.c (gcc
# 15.2.0, -O2). Seven accepted functions' frames move, in bytes:

#
# The cause, measured: gcc's inliner (-fopt-info-inline-optimized, c564e41's src/casim.c against this commit's) inlines
# small() at 46 call sites where it inlined 30, and every other decision into these seven functions is the same. small

# code tried (its helpers noinline, inlined more, cold, its small() calls behind one wrapper) brought the moves below
# seven except one that kept an unused static function, which -Werror refuses.
#   - small() newly inlined into the function itself: angle_factor (2 sites), lm_sum (3), sm_anti (2 more, 4 in all),
#     td_prop (1).
#   - into a function it inlines: integ_checked inlines canon_const, which now inlines small (1 site). mul inlines
#     exp_of, whose partial clone exp_of.part.0 now inlines small (1 site); with -fno-ipa-sra mul's frame doesn't move.
#   - ib: not traced. Its inlining decisions are unchanged, and it moves 240->272 under -fno-ipa-ra, -fno-ipa-sra and

#     change found.
#   - Ruled out as the general cause: IPA-RA. With -fno-ipa-ra both trees compiled, the same seven move.
