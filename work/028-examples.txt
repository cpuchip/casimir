# CAS 028's examples (work/028-complex-left-out.md; ruled abacus #10137, #10148, #10163; the wording soroban's,
# #10154): without the complex bit, the roots it would print counted after SOLVED's or PARTIAL's status as ", n CPLX".
# Each row is run by scripts/doc-examples.py, and again with the series route compiled out (CAS 021) and through the
# value check's build (CAS 022 rule 5). Each n is the roots the same input's answer with --complex adds, counted with
# their multiplicities (the --complex rows show two of them); tests/solve_test.c judges n on the seeded polynomials
# against their construction.

# - Each route (abacus #10148: one branch, quad_roots' negative discriminant without the bit):

| Command | Prints |
|---|---|
| `casim solve '(X-2)×(X^2+1)' X RAD` | `SOLVED, 2 CPLX: X=2` |
| `casim solve '(X^2+1)^2×(X-3)' X RAD` | `SOLVED, 4 CPLX: X=3` |
| `casim solve 'X^6-1' X RAD` | `SOLVED, 4 CPLX: X=-1; X=1` |
| `casim solve 'X^3-8' X RAD` | `SOLVED, 2 CPLX: X=2` |
| `casim solve '(X^2+1)×(X^3-2×X-5)' X RAD` | `PARTIAL, DEGREE 3 LEFT, 2 CPLX` |
| `casim --one-line steps solve 'X^4+X^2=0' X RAD` | `COMMON FACTOR: X^2×(X^2+1)=0 /   LINEAR: X^2=0: X=0 (MULT 2) /   QUADRATIC FORMULA: X^2+1=0: NO REAL ROOTS / ANSWER: SOLVED, 2 CPLX: X=0 (MULT 2)` |

# - Model 33 ignores the bit, so the note is there with it or without it (abacus #10163); outside model 33 the bit
#   prints the pair instead, as at 1.0.1:

| Command | Prints |
|---|---|
| `casim --model 33 solve '(X-2)×(X^2+1)' X RAD` | `SOLVED, 2 CPLX: X=2` |
| `casim --model 33 --complex solve '(X-2)×(X^2+1)' X RAD` | `SOLVED, 2 CPLX: X=2` |
| `casim --complex solve '(X-2)×(X^2+1)' X RAD` | `SOLVED: X=2; X=-0i1; X=0i1` |
| `casim --complex solve '(X^2+1)^2×(X-3)' X RAD` | `SOLVED: X=3; X=-0i1 (MULT 2); X=0i1 (MULT 2)` |
