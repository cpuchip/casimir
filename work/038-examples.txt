# CAS 038's examples (work/038-letters-in-solve.md; Michael's "whatever is good/next for casimir", abacus #13632, h038
# #13635): solve for a variable in an equation linear in it, whose coefficients hold other letters or π. The answer is
# put back into the equation and must give 0 before it prints, and its rows are where it holds: a≠0 for the variable's
# coefficient a, and each condition of the typed text read at the answer. Each row is run by scripts/doc-examples.py,
# and again with the series route compiled out (CAS 021) and through the value check's build (CAS 022 rule 5).

# - Part 1: formulas rearranged, in each model and mode (the answer is canon's text, as every op prints it)
