# CAS 019 fractions: visible examples (work/019-fractions.md), written by casim from the build and read again by
# scripts/doc-examples.py (make check). The default arena is 8,800 B. A status line and its answer join with " / ".

# - Rule 1: a number casim makes prints as a fraction, k×u÷d; whole numbers as before
| `casim derive "X^3÷6" X RAD` | `X^2÷2` |
| `casim integrate "X^3" X RAD` | `X^4÷4` |
| `casim integrate "X×LN(X)" X RAD` | `-X^2÷4+X^2×LN(X)÷2` |
| `casim integrate "1÷(X^2-1)" X RAD` | `LN(ABS(X-1))÷2-LN(ABS(X+1))÷2` |
| `casim integrate "X×ATAN(X)" X RAD` | `-X÷2+ATAN(X)÷2+X^2×ATAN(X)÷2` |
| `casim expand "(X+1÷2)^2" RAD` | `X+X^2+1÷4` |
| `casim subst "X^2+X" X "1÷2" RAD` | `3÷4` |
| `casim defint "X" X 0 1 RAD` | `1÷2` |
| `casim pdiv "X^2+1" X "2×X+1" RAD` | `X÷2-1÷4; 5÷4` |
| `casim cancel "(X^2-1)÷(2×X-2)" X RAD` | `X÷2+1÷2; X=1` |
| `casim taylor "EXP(X)" X 0 4 RAD` | `1+X+X^2÷2+X^3÷6+X^4÷24` |
| `casim taylor "X^3" X "1÷2" 3 RAD` | `1÷8+3×(X-1÷2)÷4+3×(X-1÷2)^2÷2+(X-1÷2)^3` |
| `casim limit "SIN(X)÷(2×X)" X 0 "" RAD` | `1÷2` |
| `casim sum "K" K 1 N RAD` | `N÷2+N^2÷2` |
| `casim simplify "SIN(30)" DEG` | `1÷2` |
| `casim simplify "1.1.2×X" RAD` | `3×X÷2` |

# - Rule 1, collect (abacus #8557 Q1): a group's coefficient folds with its power of the variable
| `casim collect "X÷4+X^2÷3+Y×X÷2" X RAD` | `X^2÷3+(Y÷2+1÷4)×X` |
| `casim collect "(1+Y)×X÷4+0.5×X^2" X RAD` | `0.5×X^2+(Y÷4+1÷4)×X` |
| `casim collect "X^2÷COS(Y)^2+X" X RAD` | `X^2÷COS(Y)^2+X` |

# - Rule 3: a number made from a marked one is marked; the CAS's own constants are not, and a shared one (the cached
