# CAS 035's examples (work/035-typed-domain.md; Michael's cas-wrong-widen (1), abacus #11335, #11402, #11436):
# sum, defint and limit print a value only where the input as typed has one. A walk over the typed tree lists each
# part's condition on its argument (a divisor ≠ 0, LN's and LOG's > 0, a root's ≥ 0, ASIN's and ACOS's ABS ≤ 1, ACOSH's
# ≥ 1, ATANH's ABS < 1, TAN's COS ≠ 0), and each op reads it: a sum's row, defint's IMPROPER (BAD_ARG for another
# letter's), limit's UNDEFINED on a side without a real value (CAS 023's rows for another letter's). Each row is run by
# scripts/doc-examples.py, and again with the series route compiled out (CAS 021) and through the value check's build
# (CAS 022 rule 5).

# - Sums: a row for each condition canon's answer doesn't show (the domain rule's u÷u, EXP(LN(u)), roots raised back,
#   0×u; and the closed form's cancelled divisor, abacus #11436 (1)); ≥ and ≤ rows; a constant with no value
