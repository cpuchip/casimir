# CAS 044's examples (work/044-trig-definite-integrals.md; abacus #17449, h044 #17455): defint of a polynomial in SIN
# and COS of one angle, where the table refuses, through CAS 042's checked antiderivative and CAS 009's bounds, interval
# check and exact values; the value in canon's form. Each row is run by scripts/doc-examples.py, at the CLI's 8,800 B,
# and again with the series route compiled out (CAS 021) and through the value check's build.

# - Part 1: at the table's bounds

| Command | Prints (lines joined by " / ") |
|---|---|
| `casim defint 'SIN(X)^2' X 0 'π' RAD` | `π÷2` |
| `casim defint 'COS(X)^4' X 0 'π÷2' RAD` | `3×π÷16` |
| `casim defint 'SIN(X)^3' X 0 'π' RAD` | `4÷3` |
| `casim defint 'SIN(X)×SIN(3×X)' X 0 'π' RAD` | `0` |
| `casim defint 'SIN(X)^2' X 0 'π÷6' RAD` | `π÷12-SQRT(3)÷8` |
| `casim defint 'SIN(X)^5' X 0 'π÷3' RAD` | `53÷480` |
| `casim defint 'COS(3×X)^2' X 0 'π÷4' RAD` | `π÷8-1÷12` |
| `casim defint 'SIN(X)×COS(X)' X 0 'π÷2' RAD` | `1÷2` |
| `casim defint 'SIN(X)^2' X 'π' 0 RAD` | `-π÷2` |
