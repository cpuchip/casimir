# CAS 025's examples (work/025-every-ratio-rows.md; abacus #9687): a ratio's rows wherever a term from lo divides,
# whatever else the ratio holds. Each row is run by scripts/doc-examples.py, and again with the series route compiled
# out (CAS 021) and through the value check's build (CAS 022 rule 5). Each answer to ∞ or to N was checked against the
# sum added term by term (sum-values.py's reader, by c25's probe: rows and values at each letter's 0 and off it).

# - Rule 2 (abacus #9687 (2)): a letter of the ratio at a negative whole power. The terms from lo divide by it from some
#   K on, and the ratio's own row has no value at its 0 (ABS(X÷Y)<1 at Y = 0), so it can't exclude it: L≠0 stands. A
#   ratio that is one letter's power with a rational constant keeps the probe, since its row (ABS(X)>v) is false at 0

|---|---|
